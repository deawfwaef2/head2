# CERVIX-3D · 头部收藏品与桌宠原型

## 先运行

**下载仓库 ZIP，解压后双击根目录 `点击开始游戏_CERVIX3D.html`，再点「点击开始游戏」。**

- 当前单文件约 **25.93 MiB**，内嵌示例头、发型 GLB、参考图与程序。无需 Node、网络或本地服务器。
- **Stage 45：画风调制器**（顶部入口）→ **自然摄影**。摄影布光、克制调色、皮肤光响应、毛孔、减油亮独立开关与调强度；支持 A/B、取消及方案 JSON。默认不启用，不覆盖原风格。总开关关闭时可先编辑参数。
- 已修复工坊预览过高裁切和角色毛孔编辑恢复到旧缓存的问题。39 项模块回归与默认离线启动通过；已主动检查截图。**眼睑、发片和头皮适配仍不够真实，本轮没有达到照片级。** 详见 [本轮验收报告](QA_REPORT_STAGE45.md)。
- 建议使用开启硬件加速、支持 WebGL2 的 Chrome / Edge。首次准备模型会显示加载提示；开始按钮在加载期间也能响应。
- HTML 版的桌宠显示在浏览器窗口内，**不是跨应用的系统桌宠**。
- 查看在线版本：<https://deawfwaef2.github.io/head2/>（部署时间与成功状态以 GitHub Pages 为准）。

## 已有功能

- 工坊：照片前视叠图、粗略肤色采样、示例骨相/发型形变、相机预设、GLB 私有导入与 PBR 保留。
- 收藏：命名、档案、注册、召唤/收回，悬停资料卡。
- 盒型空间：屏幕中心消失点、有限边界、滚轮深度、拖动、碰撞、单击切换旋转模式。
- 设置：画质、空间、交互与音效参数。延续已有 handoff 的静态表情偏好，默认无自动眨眼。
- 导出：档案 JSON 和含 `manifest.json`、`dossier.md` 的 ZIP 文件夹。

## 高保真模型的正确流程

1. 在 DAZ / Blender 中准备**您有权使用**的头部与发型，结合正面、45°、侧面参考手工拟合。
2. 在 Blender 裁掉躯干、整理颈部边环并封口；解剖底座需要另行制作。程序不会自动裁切任意全身模型。
3. 将头与发型对齐在同一场景，烘焙 glTF PBR，内嵌贴图，合并导出一份 `.glb`。
4. 在工坊步骤 2 导入。外部头默认不叠加内置发型，保留自身材质，并等比适配预览尺寸。
5. 验收各角度的发际线、透明边缘、眼睫与封口后，命名并注册。

详见 [`DAZ_ASSET_GUIDE.md`](DAZ_ASSET_GUIDE.md)；离线 HTML 的教程页也包含头发验收流程。

当前支持**内嵌贴图 GLB**，不支持直接读取 OBJ/MTL、外置 GLTF 依赖、DAZ `.DUF` 或 strand curves。单张照片不会自动生成高精三维头部。

## 保存与迁移

- 藏品参数存在本浏览器 localStorage；私人 GLB 存在本浏览器 IndexedDB。
- 浏览器禁止存储时，导入只能保留当前会话，并显示提示。
- 档案 ZIP **不包含私人模型本体**。请另存原始 GLB / BLEND / DUF，清理浏览器数据或换电脑后重新导入。
- 仅开发服务器模式可能把档案写入仓库 `collectibles/`；离线 HTML 使用本地存储与下载，不会假装已写入磁盘目录。

## 真正系统桌宠（Electron 源码）

```bash
npm ci
npm install --no-save electron
npm run electron
```

无需另开 Vite：Electron 默认读取已打包的根目录 HTML。管理器默认不置顶；切换桌宠模式后才成为透明置顶层，空白区域鼠标穿透。

恢复管理器：托盘菜单、**Ctrl/Cmd+Alt+M** 或 **Ctrl/Cmd+Alt+X**。

**本轮未提供 Windows/macOS 安装包，也未在真实系统桌面验证穿透、托盘和多屏行为。** 下载 HTML 可立即试玩，但完整系统桌宠目前仍需上述环境。

## 资产与真实性边界

- `daz_asian_head_base.glb` 是示例文件名，**不是 DAZ Genesis 商业原件**。运行时统计示例头约 10,254 顶点 / 18,142 三角面，源贴图最高 1024px。
- 旧资产构建脚本依赖旧环境 `/tmp` 上游文件，仓库尚缺完整可核验的源资产许可。商业或公开再分发前必须核验每件资产；不要将私人商业模型上传公开 GitHub。
- WebGL 实时 PBR 不等于 DAZ Iray / Blender Cycles 离线光追。
- 颈部切面为艺术解剖示意，不能用于医学判断。

合并了另一轮Stage13辉光/氛围/1024皮纹更新；软件GPU自动关闭HDR后期（设置显示不可用），保留廉价氛围效果与正常直渲。硬件GPU后期使用离屏MSAA并恢复原始Alpha覆盖；辉光强度调低到0.10、阈值1.0。真机HDR/MSAA画质与性能仍待验收。
