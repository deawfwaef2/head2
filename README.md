# CERVIX-3D · 颅相典藏馆
**3D 头部藏品管理、预览与桌宠原型**

## 先运行与当前限制
- 下载仓库 ZIP 并解压，**双击根目录 `点击开始游戏_CERVIX3D.html`**，可离线进入浏览器版；浏览器版只在该浏览器窗口显示桌宠，不能跨应用悬浮。
- 真正系统桌宠需要 Electron：`npm ci && npm install --no-save electron && npm run electron`。默认管理器是普通非置顶窗口；进入桌宠模式后空白区域鼠标穿透。**Ctrl/Cmd+Alt+M**（或 **Ctrl/Cmd+Alt+X**）、托盘菜单可恢复管理器，桌面模式行为仍须在目标 Windows/macOS/Linux 实机核验；未提供打包安装程序。
- 内置 GLB 头/发是项目合成示例，**不是 DAZ Genesis 商业原版，也不等同照片级重建**。其生成脚本引用了旧环境 `/tmp/dl_inspect/base_body.glb`，当前仓库没有包含可复核的上游下载地址与许可原件；公开分发前务必核查资产来源与再分发权。切面是艺术解剖示意，不是临床用医学数据。官方头模/发型选材、许可与 Blender 处理步骤见 [`DAZ_ASSET_GUIDE.md`](DAZ_ASSET_GUIDE.md)。
- 注册藏品保存在本浏览器 localStorage；导入的私人 GLB 存在本浏览器 IndexedDB，缺失时需要重新选原文件。档案页可下载包含 `manifest.json` + `dossier.md` 的 ZIP 文件夹，**模型本体不在 ZIP 里**。

## 一、核心功能概览

1. **高精度 Daz 风格东亚女性头部模型（仅头部 + 写实发丝 + 颈部医学解剖断面）**
   - 内置 3 套近万面（9,160 三角面头雕 + 864 三角面三维浮雕解剖切面）的东亚女性细分头模基底：
     - **「林汐 · Lin Xi」**（Daz G8.1 江南古典鹅蛋脸骨相 + 东方乌木黑长直丝感发丝 + C4 标准横切面）
     - **「苏婉 · Su Wan」**（Daz G9 精致 V 脸少女骨相 + 日式姬发公主切 + C4/C5 前倾斜切面）
     - **「千雪 · Qian Xue」**（东亚清冷直鼻骨相 + 江南温婉低盘发 360° 全露颈部断面 + C5 横切面）
   - 支持**实时骨相滑块微调**（下颌 V 线、颧弓与苹果肌、鼻梁挺度、杏眼弧度、唇珠丰满度、颈部粗细、截断高度与俯仰倾角）。
   - 支持**直接导入外部 `.glb / .gltf / .obj` 模型**（如从 Daz Studio / Blender 导出的高精模型），系统内置 WebGL 动态截断器会自动在颈部切除下方身体，并严丝合缝封口装配写实医学解剖断面。

2. **写实医学颈部横切面底座（C4/C5 水平）**
   - 底座断面由外向内精细还原 10 大解剖层级：
     1. **表皮与真皮切缘环 (Epidermis & Dermis Cut Rim)**
     2. **皮下浅筋膜黄色脂肪小叶与颈阔肌 (Subcutaneous Adipose & Platysma)**
     3. **颈深筋膜浅层与白膜肌间隔 (Investing Deep Cervical Fascia)**
     4. **双侧胸锁乳突肌与舌骨下肌群 (Sternocleidomastoid & Infrahyoid Strap Mm.)**
     5. **气管透明软骨 C 形环、呼吸黏膜与深凹气管腔 (Trachea Hyaline Cartilage & Lumen)**
     6. **紧贴气管后方的食管星状闭合黏膜腔 (Esophagus Stellate Mucosa)**
     7. **甲状腺左右叶与峡部滤泡实质 (Thyroid Gland Lobes)**
     8. **双侧颈动脉鞘：颈总动脉（厚壁鲜红动脉腔）、颈内静脉（薄壁暗蓝静脉腔）、迷走神经 (Carotid Sheath)**
     9. **第 4/5 颈椎（C4/C5）皮质骨/松质骨椎体、横突孔椎动静脉与分叉棘突 (Cervical Vertebra)**
     10. **椎管硬脊膜囊与脊髓灰质蝴蝶形前后角 (Spinal Cord Butterfly Gray Matter)**
   - 配备凹凸高度法线贴图（软骨与椎骨微凸、气管与血管腔内凹）及湿润浆膜清漆高光（Clearcoat）。

3. **屏幕中心透视消失点 + 有限盒型 3D 透视空间（True Screen-Space 3D Box Space）**
   - 桌宠直接悬浮于整个电脑屏幕层（在网页预览中可通过右上角 **「🗕 隐藏软件窗口 (纯看屏幕桌宠)」** 一键收起管理软件窗口，纯享桌面 3D 藏品）。
   - **屏幕中心为透视消失点（Vanishing Point）**，空间被设计为具有前玻璃面（`Z = 0mm`）、左右上下侧壁与远景后壁（默认 `Z = -1200mm`）的**有限盒型透视空间**。
   - **滚轮调节 3D 远近深度**：鼠标悬停在桌宠上滚动滚轮，即可将桌宠沿着透视消失点方向推入屏幕深处或拉近至屏幕玻璃面。
   - **拖拽与盒壁碰撞**：拖拽桌宠碰触盒型空间六面边界或与其他桌宠相撞时，会产生真实弹性反弹与盒壁光波纹反馈。

4. **交互模式与悬停档案浮窗**
   - **鼠标靠上去显示档案窗口**：鼠标悬停在任意屏幕桌宠上，自动弹出半透明典藏档案浮窗（显示编号、名称、评级、当前盒空间 X/Y/Z 坐标、解剖断面规格与背景记录）。
   - **3D 视线追随效果**：默认状态下，屏幕上的 3D 头部桌宠会根据鼠标在屏幕空间的位置自然转动视线与头颈角度。
   - **单击进入 360° 旋转模式，再次单击取消**：左键单击任意桌宠，即刻激活三维陀螺仪环进入 **360° 自由旋转鉴赏模式**（拖拽鼠标可任意翻转仰视底部解剖切面）；再次单击桌宠即可退出旋转模式。

5. **WebAudio 实时物理音效系统**
   - 内置纯算法合成的物理音效引擎（可在设置页独立调节音量与试听）：
     - 🤏 **拾取与放下重量感音效**
     - 💨 **随拖拽速度实时变频的空间风阻与摩擦感音效**
     - 💥 **盒型空间前玻璃面/侧壁/后壁与桌宠间物理碰撞音效**
     - 🛞 **随 Z 轴景深远近自动变调的滚轮刻度音效**
     - 🔄 **旋转模式机械陀螺仪锁定/解锁音效**

## 二、如何在本地以「真实 Windows / macOS 透明穿透桌面窗口」运行

本项目同时内置了完整的 **Electron 全屏透明置顶穿透桌面层源码**（位于 `electron/main.cjs` 与 `electron/preload.cjs`）：

```bash
# 1. 安装依赖
npm install
npm install --save-dev electron

# 2. 启动 Vite 服务
npm run dev

# 3. 在另一个终端启动 Electron 透明桌面层
npm run electron
```
Electron 先以非置顶、可从任务栏找回的管理窗口启动；切换至桌宠模式后才使用透明置顶层（`floating` 等级，避免遮盖全屏应用）。空白区域向其它窗口透传点击，鼠标命中模型时才接收操作。可用托盘 / Ctrl/Cmd+Alt+M 随时返回管理器。上方旧版“全屏透明置顶”说明以本段为准。
